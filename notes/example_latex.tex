\section{Overview}

This note is written directly in LaTeX. It is converted to a body-only HTML
fragment by pandoc and then wrapped into a page by \texttt{build\_site.py},
exactly like the Org notes. Math is left untouched for MathJax:
%
\[ \hat{P}(k) = \frac{1}{V N_k} \sum_{|\vv{p}| \in k} \delta(\vv{p}) \delta(-\vv{p}) \,. \]

Inline math and shared macros work too: the linear power spectrum
\(\PL(k)\) and the measure \(\dd^3 q\) both come from
\texttt{site/latex/macros.tex} and are expanded before MathJax sees them.

\begin{info}
Info boxes map to \verb|<div class="info">|, the same element the Org
special block produces, so they pick up the site's admonition styling.
\end{info}

\section{Displayed equations}

\begin{align}
  \avg{\delta(\vv{q}) \delta(\vv{q}')} &= (2\pi)^3 \delta_D(\vv{q} + \vv{q}') \, \PL(q) \,, \\
  \avg{\hat{P}(k)} &= \PL(k) + \text{(loop corrections)} \,.
\end{align}

def estimator(delta, n_modes):
